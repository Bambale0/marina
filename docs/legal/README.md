# Документы текущего сервиса

Тексты политики и отдельного согласия служат исходниками для административно управляемой privacy-policy. Публикуемая редакция хранится в БД, доступна без входа по `/privacy`, `/privacy/consent` и `/api/privacy/current`. Редактирование этих файлов само по себе не меняет опубликованную редакцию.

Оператор, ИНН, ОГРНИП, адрес и телефон перенесены из предоставленной владельцем оферты. Контакт Telegram перенесён из возрастных PDF. Email, использованный для входа в Lava, не назначен публичным контактом автоматически.

Политика не заменяет письменное согласие на специальные категории данных, регистрацию оператора, проверку локализации и необходимое уведомление о трансграничной передаче. Факт выполнения этих организационных процедур не подтверждается наличием документа или зелёными тестами.

- [Статья 10: специальные категории](https://www.consultant.ru/document/cons_doc_LAW_61801/26edb2934b899bf9c74c3a8f7e574651c6565e6d/).

При получении новых реквизитов или изменении фактической обработки оператор публикует новую редакцию через административный интерфейс. Сохранённые согласия содержат текст согласия, идентификатор и редакцию политики, её digest, момент принятия и отметку законного представительства. Рекламное волеизъявление хранится отдельно и может быть отозвано через `/stop`.
