# Клиентское меню Telegram: четыре входа

Согласованный экран `/menu` и возвращаемые после задач кнопки содержат только:
«Вступить в группу», «Связаться со специалистом»,
«Записаться на онлайн-занятие», «Мой кошелёк».

## Настройки ссылок

В опубликованной policy с `type=operations` можно указать:

- `group_url`: HTTPS-ссылка `https://t.me/...` на группу;
- `specialist_contact_url`: HTTPS-ссылка `https://t.me/...` для личной связи.

Если нужный ключ отсутствует, бот использует соответствующее поле последнего
опубликованного возрастного сценария: `channel_url` для сообщества
(может вести на канал, а не группу), `contact_url` для специалиста.
Для контакта существует дополнительный fallback на опубликованную policy
`consultation_routes.contact_url`. URL не хардкодятся и не берутся из
неопубликованных настроек. Невалидная ссылка не превращается в кликабельную
кнопку; пользователь видит объяснение.

## Запись на онлайн-занятие

Пока используется уже существующий `booking`: выбранный профиль,
цель занятия (тема `Онлайн-занятие: ...`), предпочтительное время,
предложение специалиста и подтверждение пользователем. Это **заявка**,
а не мгновенное бронирование и не доказательство оплаты. Для нового
клиента нужно сначала создать/выбрать профиль.

## Кошелёк

На текущем этапе экран **только информационный**: без отображения
вымышленного остатка, пополнений, списаний или создания платёжного заказа.
Доступна история существующих заказов через «Мои обращения».
Нельзя включать платёжные действия до внедрения транзакционного
ledger, привязки подтверждённых событий провайдера, идемпотентного
резервирования и списания, возвратов/сверки и отдельного тестирования.
Для услуг внутри Telegram требуется отдельно проверить применимые
правила платежей/Stars.

## Совместимость

Старые разделы доступны по команде `/services`. `/start` продолжает
открывать возрастной скрининг, `/video` — прежние задания, `/profiles` —
профили, `/admin` — админку. Старые callback из ранее отправленных
сообщений не меняются.

## Границы релиза

Изменения в этой ветке реализуют **меню и безопасную навигацию**, но не
новый тарифный движок, пакет занятий и не денежный кошелёк. Эти части
нужно выпускать отдельно после проектирования финансового контура.
