## Дальнейшая публикация

Повторное подключение именно этих четырёх файлов выполняется scripts/publish_preparation_pdfs.py с явными --database, --env-file, --files, --manifest и при необходимости --write-source. Файлы проверяются по SHA, опубликованные материалы повторно используются, административные изменения сохраняют историю. Исторический publish_consultation_remainder.py описывает этап до получения памяток; после этого этапа его нельзя использовать для сброса актуальной конфигурации.
