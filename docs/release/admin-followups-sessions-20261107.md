# Админские мостики, сохранение сессий и согласие — 07.11.2026

Основание: прямые просьбы владельца ускорить мостики для админов до 15 минут,
подключить Redis для сохранения сессий при перезапуске и исправить повторный
вопрос о рекламе после первого нажатия.

Административные касания после подтверждённой доставки PDF назначаются через
15/30/45 минут. Для клиентов остаются 24/48/72 часа из снимка сценария.
График сохраняется в прохождении; устаревшее касание пропускается после простоя,
а запись, stop и отсутствие действующего права блокируют доставку.
Срок купона и цены не изменяются.

Миграция `marina.admin_followup_migration.migrate(app, reason)` при остановленном
worker переносит только оставшиеся pending-касания действующих администраторов.
Версия, причина и аудит сохраняются; повторный запуск не сдвигает график.

Redis подключён как сохраняемое зеркало сессий по SHA-256 токена. SQLite остаётся
авторитетным реестром срока, блокировки и отзыва; старая Redis-запись не возвращает
отозванный вход. При сбое или очистке Redis доступ восстанавливается из SQLite.
Сам диалог, согласия и callbacks по-прежнему хранятся в SQLite вне каталога выпуска.
Веб-токен переживает закрытие вкладки, очищается при выходе/401 и привязан к
Telegram user ID для предотвращения показа предыдущего аккаунта.

Сервис marina-redis работает от marina через приватный Unix socket без TCP-порта,
с AOF и fsync каждую секунду, автозапуском и каталогом /var/lib/marina/redis.
Не открывать socket другим пользователям. Redis не заменяет резервные копии SQLite.

Повтор вопроса о рекламе вызывался тем, что payload старой callback-кнопки
перезаписывал действие новой кнопки. Теперь действие создаваемой кнопки имеет
приоритет; сохранённые кнопки прежнего выпуска также обрабатываются корректно.

Проверки и результаты развёртывания дополняются по факту; коммерческая приёмка и
изменение main этой работой не выполняются.

## Выполненные проверки

RED воспроизвёл суточные админские задержки, отсутствие Redis-записи при входе
и повтор запроса рекламы по первому нажатию. После исправлений 30 новых тестов
прошли: расписание, миграция, отмена, отзыв и срок входа, остановка/перезапуск
Redis, продолжение диалога, старые callbacks и настоящий Chromium.
ruff check marina, ruff format --check marina tests, compileall и bash -n прошли.
