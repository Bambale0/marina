# Кнопки консультаций по авторскому документу — 05.11.2026

Владелец потребовал устранить два выявленных несоответствия: отложенный вопрос сразу открывал Telegram, а ряд названий был унифицирован. Источник — ДЛЯ БОТА ОСТАТОК.pdf (SHA-256 10bcb424f6addf4de44516071935bd6cc911e44bdfb9dd92f645ca8f79158b0b) и присланный текст.

Теперь вопрос из отложенных сообщений является callback funnel_contact владельца прохождения. Бот показывает возрастной ответ из документа, а следующий URL открывает личный Telegram с возрастным предзаполненным текстом. Такая же последовательность применяется к дополнительным кнопкам вопроса в воронке.

В извлекаемый авторский сценарий добавлены девять редактируемых подписей: информация, запись по промокоду, обычная запись, целевая запись, вопрос в описании, вопрос в отложенном сообщении, личный диалог, оплата, возврат. Названия берутся из соответствующих разделов документа. В заголовках с альтернативой через «/» выбрана первая формулировка. Имя-плейсхолдер заменено действующим именем специалиста. Взрослая ветка использует своё «Задать вопрос в личные сообщения». Изменяется только опубликованная редакция через admin API; поля доступны в редакторе админки.

Оплата подписана «Оплатить диагностику {price}» как при подтверждении расчёта, так и на готовой защищённой ссылке и при повторном открытии счёта. Сумма читается из серверного расчёта/снимка заказа и форматируется с пробелами тысяч. При отсутствии права на купон используется полная сумма и нейтральная подпись записи. Старые финансовые снимки и исходные PNG-в-PDF не меняются. Отложенный рендер понимает динамический price. Публикация отклоняет отсутствующую сумму оплаты, неизвестные плейсхолдеры, конверсии и format specifiers.

Для старых прохождений без нового раздела кнопок презентация использует опубликованные подписи, сохраняя исходные снимки. Существующие callbacks остаются совместимыми. Уже отправленные сообщения Telegram не переписываются: новое поведение применяется к вновь отправляемым сообщениям.
