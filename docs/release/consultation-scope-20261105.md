# Консультации, состав продукта и политика данных — 05.11.2026

Владелец разрешил публикацию консультаций по возрастным PDF, динамическую сумму по условиям купона, удаление подписки/тренажёра и асинхронного разбора из текущего продукта, подготовку и публикацию политики данных.

## Цены и продукты Lava

Четыре консультации опубликованы в кабинете Neiro-skrining. Отдельным GET `/api/v2/products?feedVisibility=ALL` подтверждены `type=CONSULTATION`, `isDynamicPrice=true` и разные offer ID. Нулевые базовые цены в таком ответе — настройка динамического продукта, а не бесплатная консультация.

Описание услуги и купона перенесено из сохранённой дословной сверки страницы 13 соответствующего PDF. В коротком заголовке Lava соблюдён лимит 80 символов; полный заголовок и содержание есть в описании. Контакт после оплаты ведёт к специалисту из PDF. Исходные документы не изменялись.

Расчёт выполняется по сохранённой заявке и праву на купон. Отсутствие права, истечение до записи или отзыв права до записи дают полную цену. Уже законно закреплённые условия заявки сохраняются при более позднем согласовании времени. Для подростков применяется точная сумма 4500 ₽ из PDF; она не вычисляется заново из указанного там округлённого процента.

`tests/test_consultation_dynamic_invoices.py` проверяет восемь вариантов через публичные quote → order → checkout → worker, точные `offerId`, RUB и сумму, игнорирование клиентской цены и отсутствие второго POST при повторном checkout. Внешний HTTP в тестах заменён. Успешное прохождение такого теста не объявляется реальным клиентским списанием.

Официальный контракт Lava: [произвольная сумма и режим «Цена по запросу API»](https://developers.lava.top/ru), [OpenAPI](https://gate.lava.top/docs). Нужен POST `/api/v3/invoice`, отдельный offer выбранного продукта и сумма сохранённого серверного расчёта; менять базовую цену общего продукта для каждой покупки не требуется.

## Отключённые услуги

Опубликованная operations-policy содержит `enabled_services`; меню, клиентский каталог, новые расчёты, заказы, checkout и создание занятий/разборов учитывают этот список. Удаление услуги не удаляет историю и не выбрасывает пришедшие позднее деньги. Старые права и уже оказанные услуги не переписываются.

## Данные и согласия

Добавлены публичные `/privacy`, `/privacy/consent`, `/offer`; документы доступны без входа и HTML-экранируются. Публикуемая privacy-policy управляется через админку; исходные тексты и правовые источники находятся в `docs/legal/`.

В боте политика и отдельное согласие выдаются разными файлами. Совершеннолетие или законное представительство подтверждается отдельно. Рекламные сообщения требуют самостоятельного добровольного выбора; отказ не препятствует основной услуге. Состояние проверяется повторно непосредственно при отправке касаний. `/stop` отзывает рекламный выбор.

«Мои данные» позволяет получить документы, выгрузить данные, отозвать согласие и подать запрос удаления. Отзыв закрывает новый сбор на этом согласии и ставит запрос оператору, сохраняя историю; повторное согласие создаёт новый доказуемый факт. Мгновенное уничтожение обязательных финансовых записей не обещается.

## Применение настройки

`scripts/publish_consultation_scope.py` принимает проверенный JSON вне Git с реквизитами опубликованных продуктов и текстами документов. Сначала выполняется на копии БД. Затем штатными административными API публикует версии оферты, правил, продуктов и воронок с причиной и историей. Проверяет реальные динамические offer через GET Lava, контрольные суммы PDF и неизменность существующих финансовых фактов, обращений и файлов. В конце отзывает созданную административную сессию.

Для рабочего применения нужны резервная копия БД и исходного JSON, успешно проверенный коммит, обновление source-конфигурации и отключение `DEV_OFFER_BYPASSES_CONSENT`. Проверки после развёртывания включают публичные документы, состояние процессов, единственную актуальную связку каждого возраста с его консультацией, недоступность удалённых услуг и пересмотр остаточных задач сверки. Результаты применения сохраняются вне Git в `/var/lib/marina/content/`.
