## Оплата консультаций в боте и проверка цен

По уточнению владельца консультация оформляется через Telegram: заявка → предложение времени → подтверждение клиентом → серверный расчёт → email → защищённая страница Lava.top → проверка поступления → подтверждение оплаты. Возрастной сценарий не требует создавать дополнительный профиль ребёнка. Для администратора сохраняется доступ без списания. Цена и условия берутся из сохранённой заявки; клиентские `amount`, `discount`, `product_id` не управляют суммой. Активная скидка закрепляется при записи и сохраняется, если время согласовано после окончания семи дней. Новая заявка без действующего купона оплачивается по полной сохранённой цене.

Защиты: отменённая/неподтверждённая/оплаченная запись не получает новый checkout; позднее или повторное поступление учитывается в финансовом журнале и отправляется на сверку. Повторный webhook не создаёт повторную услугу. Сервис по подключённому коммерческому тарифу нельзя завершить или выдать ссылку встречи до оплаты. Подтверждение времени само по себе оплатой не считается.

При отмене оплаченной консультации создаётся одна задача ручной сверки возврата без удаления поступления, `order_id` или `paid_at`. Задержавшееся подтверждение оплаты не обещает отменённую встречу. Каждая подтверждённая доставка клиенту/администратору сохраняется отдельно, поэтому отказ отправки одному получателю не повторяет уже доставленное другому. Администратор получает прямую кнопку заявки. Неустранимая общей транзакцией Telegram/SQLite авария после внешней отправки до локального ACK по-прежнему может повторить сообщение.
